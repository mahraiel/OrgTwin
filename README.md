# OrgTwin

OrgTwin project source package. The cleaned source archive is included as `OrgTwin_GitHub_Ready.zip`.

## Run locally

1. Extract the ZIP archive.
2. Install dependencies: `pip install -r requirements.txt`
3. Run tests: `python -m unittest discover -s tests -v`
4. Start demo: `python run_demo.py`

Optional Anthropic narration uses `ANTHROPIC_API_KEY` from your local environment. Never commit real API keys.

See the ZIP for the full source tree and project documentation.
